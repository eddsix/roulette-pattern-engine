# Roulette Pattern Lab v12.0

Standalone rebuild. No external libraries or network dependencies.

Core features:
- 0–36 result input with press animation
- Persistent local history
- CW/CCW and pocket jumps
- Real-time prediction after 12 spins
- 37-pocket ranking and model probability
- ±1 through ±9 evaluation
- WIN/LOSS prediction history
- Sequence, jump, joint jump+direction, pair and transition pattern families
- Walk-forward adaptive weights
- Persistent pattern library
- TXT export and JSON backup/restore
- Day/night mode persisted locally
- Responsive horizontal swipe containers for result/jump/direction history
- Dashboard chart

The model is statistical pattern analysis, not a guarantee of future roulette outcomes.
