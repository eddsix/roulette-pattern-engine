# Roulette Pattern Lab v0.2

Aplicación web móvil experimental.

Abre `index.html` en un navegador moderno. Los resultados se guardan localmente en el navegador.

Incluye rueda europea, distancias físicas, vecinos, patrones básicos de transición y distancia, consenso, registro de predicciones y métricas de backtest.

No utiliza visión artificial, tracking ni apuestas automáticas. No demuestra que la ruleta sea predecible.
